# Hydrogen

A website which would help people with periodic table breaking bad style like the whole motivation for this website was my interest in inorganic chemistry.

## How it works 

Element data is stored in elements.js. React creates a button for each element. Now when you click the element the react state changes which shows the element details.
Now for changing the background a helper determines the element’s actual period and selects the corresponding character photograph.
## Features 
- A button for changing the font of the website.
- 7 buttons for changing the background of the website according to the elements and characters.
